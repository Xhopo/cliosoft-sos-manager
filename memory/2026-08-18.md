# 2026-08-18

## SOS Manager full-scan trigger audit

- Audited the current v0.46 implementation after the user asked whether the full Changed Files scan could be mis-triggered.
- `performFullWorkspaceScan()` has one direct call, in the `refreshFilteredStatus` command. A visibility listener still indirectly executes that command when the Changed Files view becomes visible, the tree is empty, and no disk cache exists.
- Current state: file-operation-triggered full scans were removed, but strict manual-only behavior is not yet implemented. No code change was made during this audit; the next targeted fix is to remove or replace the visibility listener's automatic command execution.
